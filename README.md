🛒 Customer Segmentation Using RFM Analysis in E-Commerce

A data analysis project that segments e-commerce customers using the RFM (Recency, Frequency, Monetary) framework to help build better marketing strategies.

📁 Files in this Project
| File | Description |
|---|---|
| `Ecommerce_Data_Analysis.ipynb` | Main analysis notebook |
| `Customer_Segmentation_RFM_Analysis.pptx` | Project presentation |
| `Ecommerce_Dashboard.pbix` | Power BI dashboard |

📊 Dataset

- Source: Kaggle – E-Commerce Data
- Size: 541,909 rows × 8 columns
- Period: December 2010 – December 2011
- Dataset Link : https://www.kaggle.com/datasets/carrie1/ecommerce-data

🚀 What I Did : 

Cleaned the data — removed missing values, duplicates, and cancelled orders
Explored the data — sales trends, day-wise patterns, top products
Pareto Analysis — 26% of customers drive 80% of revenue
RFM Scoring — scored each customer on Recency, Frequency, and Monetary value (scale of 1–5)
Segmentation — grouped customers into High Value, Loyal, At-Risk, and Dormant
Recommendations — marketing strategies for each segment


🧩 Customer Segments
| Segment | Behaviour | Strategy |
|---|---|---|
| 🏆 High Value | Recent, frequent, high spenders | Loyalty programs & VIP perks |
| 💛 Loyal | Consistent buyers | Upsell & cross-sell |
| ⚠️ At-Risk | Declining engagement | Personalised re-engagement offers |
| 😴 Dormant | Inactive customers | Win-back campaigns |
